# MiniAV — Architecture Decision Records

- **ADR-001 (Accepted):** Hybrid design: an in-house SHA-256 demonstration engine with optional external scanning adapters.
- **ADR-002 (Accepted):** C# / .NET 10, with CLI first and WPF later.
- **ADR-003 (Accepted):** No kernel driver or system-wide real-time protection in early milestones.
- **ADR-004 (Accepted):** Separate read-only detection from any future remediation.
- **ADR-005 (Provisional):** Use ClamAV in a separate process; licensing, packaging, and safety require review. M3 remains a draft integration.
- **ADR-006 (Open):** Prioritize Windows 11; Windows 10 compatibility scope to be decided.
- **ADR-007 (Updated):** This GitHub repository is the project source and documentation record; the repository is now public. Stable work is maintained on `main`, with experimental work isolated in branches.

These are engineering decisions, not proof that optional or future features have shipped.
