# MiniAV 路线图

| 里程碑 | 交付物 | 状态 |
|---|---|---|
| M0 | 项目结构、文档、只读 CLI 原型 | 完成 |
| M1 | Windows 编译与测试、Core/Engine 模块化、错误与取消处理、基础扫描数量限制 | 完成，PR #1 已合并 |
| M2 | WPF GUI、扫描进度、日志、取消；补齐扫描资源限制 | 进行中（feature/m2-scan-foundation） |
| M2.1 | 安全隔离和可逆恢复（仅明确授权） | 待开发 |
| M3 | 可选 ClamAV 集成、签名更新 | 待开发 |
| M4 | 并发、增量缓存、性能优化 | 待开发 |

M2 开发顺序：扫描资源保护与进度契约 → WPF 基础界面 → 日志与取消 → Windows 端到端验证。

当前 SHA-256 引擎仅使用无害演示签名，不能提供实际杀毒覆盖，也不替代 Windows Defender。
